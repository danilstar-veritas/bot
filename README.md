# Barber Bot — AI-адміністратор для барбершопу в Telegram

Бот записує клієнтів на послуги, відповідає на питання, нагадує про візит і передає складні розмови власнику. Один запущений бот-сервер обслуговує скільки завгодно закладів: у кожного свій Telegram-бот і свій файл налаштувань.

Написано на чистому Python — **нічого, крім самого Python 3.11+, встановлювати не треба**.

## Що вміє

**Для клієнта**
- Запис кнопками: послуга → майстер (або «будь-який») → день → час → підтвердження. Показується лише справді вільний час.
- AI-чат: можна просто написати «хочу на стрижку завтра ввечері» — бот знайде вільний час і покаже картку з кнопкою «✅ Підтвердити». Запис створюється **тільки після натискання** (або короткого «так»), тож AI не може записати когось помилково чи вигадати вікно.
- «🗓 Мої записи»: перенесення і скасування без участі адміністратора.
- Нагадування за 24 год і за 2 год з кнопками «Прийду / Перенести / Скасувати».
- Через 4 тижні після візиту — «записати вас знову?».
- Ціни, адреса, графік, кнопка «на карті». Мова кнопок — українська, російська або англійська (за мовою Telegram клієнта); AI відповідає мовою клієнта.

**Для власника закладу**
- Сповіщення про кожен новий запис, перенесення, скасування.
- Передача розмови людині: скарга, знижка, повернення грошей, оплата, «покличте адміністратора», фото/скріншот. Власник відповідає прямо в Telegram (реплаєм), бот пересилає клієнту, AI в цей час мовчить.
- Команди: `/today`, `/tomorrow`, `/week`, `/stats`, `/block` (вихідний, відпустка, запис по телефону), `/pause`, `/resume`, `/reload`.
- Щоранку — розклад на день.
- `/stats` — записи (скільки через AI, скільки вночі), неявки, частка діалогів без участі людини, вартість AI. Це головний аргумент, коли продаєте бота наступним закладам.
- Щовечора (21:00, `report_at`) — підсумок дня: візити, виручка по майстрах, неявки, скільки записів на завтра.

**Захист**
- AI бачить лише записи поточного клієнта і не може нічого змінити без підтвердження кнопкою.
- Ігнорує спроби «забудь інструкції», не обговорює сторонні теми, не підтверджує оплату.
- Ліміти: повідомлень від одного клієнта на годину/добу і токенів AI на добу для кожного закладу.
- Якщо AI недоступний (немає грошей на балансі, збій) — бот далі працює на кнопках, а вам приходить сповіщення.

## Структура

```
run.py                         запуск і службові команди
config/settings.toml           ключ AI, модель, ліміти
config/tenants/*.toml          по файлу на кожен заклад (приклад: demo-barbershop.toml)
config/eval.toml               тестові діалоги для перевірки AI
barberbot/                     код бота
tests/                         автотести (130 тестів)
deploy/barberbot.service       автозапуск на сервері (Linux)
data/                          з'явиться після запуску: база bot.db і журнал bot.log
```

## Перший запуск на Mac (≈15 хвилин)

### 1. Встановіть Python
Завантажте macOS-інсталятор з https://www.python.org/downloads/ (версія 3.12 або новіша) і встановіть.
Потім відкрийте **Програми → Python 3.x** і двічі клацніть **Install Certificates.command** — без цього Python на Mac не зможе підключитися до Telegram.

### 2. Створіть бота в Telegram
1. Напишіть [@BotFather](https://t.me/BotFather) команду `/newbot`.
2. Вкажіть назву (наприклад, «Бритва — запис») і username, що закінчується на `bot`.
3. BotFather надішле **токен** виду `1234567890:AAH...` — скопіюйте його.

### 3. Вставте токен
Відкрийте `config/tenants/demo-barbershop.toml` у редакторі коду (рекомендую безкоштовний [VS Code](https://code.visualstudio.com/)) і замініть `ВСТАВТЕ_ТОКЕН_ВІД_BOTFATHER` на свій токен (лапки залиште).

> TextEdit на Mac сам замінює лапки " на «розумні» “ ”, і файл перестає читатися. Якщо все ж редагуєте в TextEdit — увімкніть Формат → Простий текст і вимкніть «Розумні лапки» в Правка → Заміни.

### 4. Перевірте і запустіть
Відкрийте **Термінал** (Cmd+Пробіл → «Термінал»), введіть `cd ` (з пробілом), перетягніть у вікно папку `barber-bot` і натисніть Enter. Далі:

```bash
python3 run.py check
```

Якщо все гаразд — запускайте:

```bash
python3 run.py
```

Напишіть своєму боту `/start` — з'явиться меню. Зупинити бота: **Ctrl+C**.

### 5. Зробіть себе адміністратором
Напишіть боту `/myid`, скопіюйте число і впишіть у файл закладу: `admins = [123456789]`. Перезапустіть бота (Ctrl+C, потім `python3 run.py`) — тепер вам приходять сповіщення про записи, а команда `/admin` відкриває панель власника.

### 6. Увімкніть AI
1. Зареєструйтесь на https://console.anthropic.com, поповніть баланс на кілька доларів (для тестів вистачить надовго).
2. **Settings → API Keys → Create Key**, скопіюйте ключ (`sk-ant-...`).
3. Вставте його в `config/settings.toml`: `anthropic_api_key = "sk-ant-..."`.
4. `python3 run.py check` → має з'явитися «Ключ Anthropic працює». Перезапустіть бота.

Тепер боту можна писати звичайним текстом.

> Поговорити з AI-адміністратором можна й без Telegram — одразу після кроку 6: `python3 run.py chat`.

## Перевірка AI перед тим, як віддати клієнту

```bash
python3 run.py chat       # розмова з AI у терміналі, як клієнт (дані не зберігаються)
python3 run.py eval       # 14 тестових діалогів із config/eval.toml: ціни, запис, знижки, скарги, злам промпту…
python3 run.py dialogs    # вивантажити реальне листування за 7 днів у data/ — розбирати помилки
python3 run.py test       # автотести коду
```

Додавайте в `config/eval.toml` питання, які реально ставлять клієнти конкретного закладу — так ви ловите помилки AI до того, як їх побачить клієнт.

## Команди власника (у Telegram)

| Команда | Що робить |
|---|---|
| `/admin` | панель і статус AI |
| `/today`, `/tomorrow`, `/day 30.10` | записи на день: ◀️ ▶️ між днями, 📅 будь-яка дата, фільтр за майстром |
| `/week`, `/all` | записи на 7 днів / усі майбутні (скасовані — окремо, з кнопкою «🧹 Прибрати») |
| *натиснути запис* | картка запису: 🔁 перенести, 🗑 скасувати, 🚫 не прийшов, 💳 оплату отримано, 👤 клієнт, ✉️ написати |
| `/book` | записати клієнта (дзвінок, візит) |
| `/find Іван`, `/find 0671` | пошук клієнта: історія візитів, неявки, сума, майбутні записи, «📞 Записати» |
| `/stats`, `/stats 7` | статистика й виручка за 30 (7) днів, по майстрах |
| `/export`, `/export 90` | файл Excel із записами за 30 (90) днів і всіма майбутніми |
| `/block andriy 30.10` | закрити весь день майстру (відпустка, лікарняний) |
| `/block andriy 30.10 14:00-16:00 запис по телефону` | закрити проміжок |
| `/block all 31.12` | вихідний для всіх |
| `/blocks` | список закритого часу, натисніть, щоб видалити |
| `/pause` / `/resume` | вимкнути / увімкнути AI (усі повідомлення йдуть власнику) |
| `/reload` | застосувати зміни з файлу налаштувань без перезапуску |

Відповісти клієнту: свайп вліво на повідомлення, яке переслав бот → написати відповідь. Кнопка «▶️ Повернути бота» знову вмикає AI для цього клієнта (або це станеться саме через 12 годин).

## Як підключити нового клієнта

1. Зберіть у закладу дані (анкета нижче).
2. Скопіюйте `config/tenants/demo-barbershop.toml` під новою назвою латиницею, наприклад `brutal-barber.toml`, і заповніть.
3. Створіть для закладу окремого бота в @BotFather і вставте токен.
4. Власник пише боту `/myid` → його ID в `admins`.
5. `python3 run.py check`, потім перезапуск. Один процес обслуговує всі заклади одразу.

Тимчасово вимкнути заклад (наприклад, не оплатив): `enabled = false` і перезапуск.

**Анкета для закладу**
- Назва, адреса, телефон, посилання на Google Maps, як дістатися/паркування, способи оплати.
- Послуги: назва, тривалість у хвилинах, ціна, короткий опис.
- Майстри: ім'я, які послуги робить, графік по днях, перерви, вихідні.
- Правила: за скільки годин можна скасувати, чи потрібен телефон, на скільки днів уперед записувати.
- Свята й неробочі дні.
- Що ще часто питають клієнти (кава, діти, сертифікати, тварини…) — це піде в `extra`.
- Хто отримує сповіщення (Telegram ID власника/адміністраторів).
- Стиль спілкування: на «ви» чи на «ти», жартівливо чи стримано.

**Як продавати:** зробіть демо-бота на `demo-barbershop.toml` і дайте власнику самому записатися. Далі пілот на 2–4 тижні в реальному закладі: `/stats` покаже, скільки записів прийшло через бота (і скільки вночі), скільки діалогів бот закрив сам і скільки стало неявок.

## Запуск 24/7 на сервері

На Mac бот працює, лише поки ноутбук увімкнений і не спить. Для реальних клієнтів потрібен сервер (VPS) — від ~$5 на місяць (Hetzner, DigitalOcean, Contabo тощо). Обирайте **Ubuntu 24.04**: там уже є потрібний Python.

```bash
# на Mac: скопіювати папку бота (уже з вашими налаштуваннями) на сервер.
# Наберіть «scp -r », перетягніть папку barber-bot у вікно Термінала, допишіть « root@IP:/opt/»
# (IP — адреса вашого сервера) і натисніть Enter.
scp -r /шлях/до/barber-bot root@IP:/opt/

# на сервері (підключення: ssh root@IP)
cd /opt/barber-bot
python3 --version               # має бути 3.11 або новіший
python3 run.py check

useradd -r -s /usr/sbin/nologin barberbot
chown -R barberbot /opt/barber-bot
cp deploy/barberbot.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now barberbot
cp deploy/barberbot-backup.service deploy/barberbot-backup.timer /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now barberbot-backup.timer   # щоденна резервна копія бази о 04:30

journalctl -u barberbot -f      # подивитися журнал (вихід — Ctrl+C)
```

Після змін у налаштуваннях: `systemctl restart barberbot` (або `/reload` у Telegram, якщо міняли лише ціни, послуги чи графік).

**Важливо:** один бот (токен) не можна запускати у двох місцях одночасно — коли перенесете бота на сервер, на Mac його зупиніть.

**Резервні копії:** щодня о 04:30 (за Києвом) бот сам робить копію бази в `data/backups/` і зберігає 7 останніх. Вручну: `python3 run.py backup`. Скопіювати копії собі: `scp -r root@IP:/opt/barber-bot/data/backups ~/Desktop/`.

## Скільки коштує AI

Модель за замовчуванням — Claude Haiku 5.5 ($0.10 за 1 млн вхідних токенів і $0.50 за 1 млн вихідних станом на жовтень 2026; актуальні ціни — https://platform.claude.com/docs/en/about-claude/pricing). Інструкції та дані закладу кешуються, тож одне повідомлення клієнта обходиться приблизно в $0.001. Для невеликого барбершопу це орієнтовно $1–3 на місяць. Точні цифри по кожному закладу — у `/stats`. Захист від перевитрат — `daily_token_limit` у `settings.toml`.

## Персональні дані

Бот зберігає імена, телефони й листування клієнтів у `data/bot.db` на вашому сервері, а тексти повідомлень для AI передаються в Anthropic API. Тримайте `config/` і `data/` у секреті (там токени, ключ і дані клієнтів). Для закладів у ЄС власнику варто мати коротку політику конфіденційності.

## Якщо щось не працює

| Симптом | Що робити |
|---|---|
| `Потрібен Python 3.11 або новіший` | встановіть Python з python.org і запускайте саме `python3` |
| «Не вдається перевірити SSL-сертифікат» | Програми → Python 3.x → Install Certificates.command |
| «Цей бот уже запущено в іншому місці» | зупиніть другу копію (інший ноутбук чи сервер) |
| Власнику не приходять сповіщення | власник має хоча б раз натиснути `/start` у боті, а його ID — бути в `admins` |
| Помилка в `.toml` | `python3 run.py check` покаже файл, поле і що виправити |
| AI відповідає «зараз не можу відповісти» | перевірте баланс і ключ на console.anthropic.com; бот надіслав вам деталі |
